to be: no BeamNG.Earth file is copied into this mod, so there is no MIT condition to

WHAT IS USED: JAMMER talks to BeamNG.Earth's speed-camera module through its public
interface when that mod is installed. It requests the 'speed' trigger only, hands a
third party's own callback back verbatim, and on unload leaves Earth's module table
byte-identical to as found.

WHAT IS NOT USED: no BeamNG.Earth file is copied into this mod. An independent
line-level comparison against Earth's speedtraps.lua found four shared lines, all of
them trivial Lua idiom (an empty module table, an empty table, two loop headers).

This notice is included because JAMMER names and depends on Earth's interface, and
because being able to say exactly what was and was not taken is worth more than the
few lines it costs.
